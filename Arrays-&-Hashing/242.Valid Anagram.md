# 242. Valid Anagram

* Problem Link: [LeetCode 242 Valid Anagram](https://leetcode.com/problems/valid-anagram/description/)
* Difficulty: Easy
* Data Structure / Technique: Hash Table / Frequency Counting

## Problem Statement

Given two strings `s` and `t`, return `true` if `t` is an anagram of `s`, and `false` otherwise.

### Example 1
* Input: `s = "anagram"`, `t = "nagaram"`
* Output: `true`

### Example 2
* Input: `s = "rat"`, `t = "car"`
* Output: `false`

### Constraints
* `1 <= s.length, t.length <= 5 * 10^4`
* `s` and `t` consist of lowercase English letters.

## Pattern & Clues (Identification)

* Key Statement: "return true if t is an anagram of s, and false otherwise"
* Clue / Insight: Validating an anagram requires both strings to have the exact same characters with identical frequencies, pointing directly to a Hash Table or Frequency Counting pattern.
* Pattern:
  * In C++, using an `unordered_map<char, int>` allows counting each character in `s` by incrementing its frequency and decrementing it for every character in `t`. If all frequencies evaluate to zero at the end, the strings are anagrams.
  * In Python, `collections.Counter` constructs a frequency hash map for both strings and verifies equality via direct dictionary comparison (`==`).

## C++ Solution

```cpp
class Solution {
public:
    bool isAnagram(string s, string t) {
        unordered_map<char, int> um;
        for(char c: s)
        {
            um[c]++;
        }
        for(char c: t)
        {
            um[c]--;
        }
        for(pair<int, int> x : um)
        {
            if(x.second != 0)
            {
                return false;
            }
        }
        return true;
    }
};
```

## Python Solution

```python
from collections import Counter

class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        return Counter(s) == Counter(t)
```

## Complexity Analysis

* C++ Solution (Hash Map Frequency Counter):
  * Time Complexity: O(n + m) where n is the length of string s and m is the length of string t, since both strings are traversed linearly.
  * Space Complexity: O(1) auxiliary space because the input consists only of lowercase English letters, bounding the hash map size to a maximum of 26 unique keys.

* Python Solution (`Counter(s) == Counter(t)`):
  * Time Complexity: O(n + m) to count character frequencies across both strings and perform the equality check.
  * Space Complexity: O(1) auxiliary space because the alphabet size is fixed to 26 lowercase English letters.

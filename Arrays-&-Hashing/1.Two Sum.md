# 1. Two Sum

* Problem Link: [LeetCode 1 - Two Sum](https://leetcode.com/problems/two-sum/description/)
* Difficulty: Easy
* Data Structure / Technique: Hash Table / One-Pass Hash Map

## Problem Statement

You are given an array of integers `nums` and an integer `target`, return indices of the two numbers such that they add up to `target`.

You may assume that each input would have exactly one solution, and you may not use the same element twice.

You can return the answer in any order.

### Example 1
* Input: `nums = [2,7,11,15]`, `target = 9`
* Output: `[0,1]`
* Explanation: Because `nums[0] + nums[1] == 9`, we return `[0, 1]`.

### Example 2
* Input: `nums = [3,2,4]`, `target = 6`
* Output: `[1,2]`

### Example 3
* Input: `nums = [3,3]`, `target = 6`
* Output: `[0,1]`

### Constraints
* `2 <= nums.length <= 10^4`
* `-10^9 <= nums[i] <= 10^9`
* `-10^9 <= target <= 10^9`
* Only one valid answer exists.

## Pattern & Clues (Identification)

* Key Statement: "return indices of the two numbers such that they add up to target"
* Clue / Insight: Instead of a nested loop checking every pair in O(n^2) time, you can check whether the complementary value (`target - nums[i]`) already exists in O(1) time using a Hash Map.
* Pattern:
  * In C++, an `unordered_map<int, int>` stores the values encountered alongside their indices. For each element `nums[i]`, calculate `c = target - nums[i]`; if `c` is already in the map, return `{um[c], i}` immediately. Otherwise, insert `nums[i]` with its index `i`.
  * In Python, a dictionary `d` serves the same purpose, mapping previous values to their corresponding index for instant O(1) lookup of `target - nums[i]`.

## C++ Solution

```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int, int> um;
        int n = nums.size();
        for (int i = 0; i < n; i++) {
            int c = target - nums[i];
            if (um.find(c) != um.end()) {
                return {um[c], i};
            }
            um[nums[i]] = i;
        }
        return {};
    }
};
```

## Python Solution

```python
class Solution:
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        d = {}
        n = len(nums)
        for i in range(n):
            x = target - nums[i]
            if x in d:
                return [d[x], i]
            d[nums[i]] = i
        return []
```

## Complexity Analysis

* C++ Solution (One-pass Hash Map):
  * Time Complexity: O(n) on average because we traverse the list of n elements once, and `unordered_map` operations (`find` and insertion) take O(1) average time.
  * Space Complexity: O(n) auxiliary space to store at most n key-value pairs in the hash map.

* Python Solution (One-pass Dictionary):
  * Time Complexity: O(n) because dictionary lookup (`x in d`) and insertions take O(1) average time across the n elements.
  * Space Complexity: O(n) auxiliary space to store elements and their indices in the dictionary.

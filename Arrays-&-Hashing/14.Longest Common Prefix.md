# 14. Longest Common Prefix

* Problem Link: [LeetCode 14 - Longest Common Prefix](https://leetcode.com/problems/longest-common-prefix/)
* Difficulty: Easy
* Data Structure / Technique: String / Horizontal Scanning

## Problem Statement

Write a function to find the longest common prefix string amongst an array of strings.

If there is no common prefix, return an empty string `""`.

### Example 1
* Input: `strs = ["flower","flow","flight"]`
* Output: `"fl"`

### Example 2
* Input: `strs = ["dog","racecar","car"]`
* Output: `""`
* Explanation: There is no common prefix among the input strings.

### Constraints
* `1 <= strs.length <= 200`
* `0 <= strs[i].length <= 200`
* `strs[i]` consists of only lowercase English letters if it is non-empty.

## Pattern & Clues (Identification)

* Key Statement: "find the longest common prefix string amongst an array of strings"
* Clue / Insight: A prefix must match from index 0 across all strings. Trimming an initial candidate prefix from the end until it matches the start of each subsequent string guarantees narrowing down to the exact common prefix (Horizontal Scanning).
* Pattern:
  * In C++, initialize `prefix = strs[0]`, iterate through the rest of the strings, and while `strs[i].find(prefix) != 0`, truncate the last character using `substr(0, prefix.size() - 1)`. If the prefix becomes empty, return `""` immediately.
  * In Python, take `prefix = strs[0]` and iteratively shorten it via string slicing `prefix = prefix[:-1]` until `strs[i].find(prefix) == 0`.

## C++ Solution

```cpp
class Solution {
public:
    string longestCommonPrefix(vector<string>& strs) {
        string prefix = strs[0];
        for(int i = 1; i < strs.size(); i++)
        {
            while(strs[i].find(prefix) != 0)
            {
                prefix = prefix.substr(0, prefix.size() - 1);
                if (prefix.empty())
                {
                    return "";
                }
            }
        }
        return prefix;
    }
};
```

## Python Solution

```python
class Solution:
    def longestCommonPrefix(self, strs: list[str]) -> str:
        if not strs:
            return ""
        prefix = strs[0]
        for i in range(1, len(strs)):
            while strs[i].find(prefix) != 0:
                prefix = prefix[:-1]
                if not prefix:
                    return ""

        return prefix
```

## Complexity Analysis

* C++ Solution (Horizontal Scanning):
  * Time Complexity: O(S) where S is the sum of all characters across all strings in the worst case (or O(n * m) where n is the number of strings and m is the length of the shortest string).
  * Space Complexity: O(1) auxiliary space (ignoring the memory created by intermediate temporary substrings during slicing).

* Python Solution (Horizontal Scanning):
  * Time Complexity: O(S) where S is the total number of characters across all strings, as each character comparison and slice operation is bounded by the string lengths.
  * Space Complexity: O(1) auxiliary space beyond the storage for the prefix slice strings.

# 169. Majority Element

* Problem Link: [LeetCode 169 - Majority Element](https://leetcode.com/problems/majority-element/description/)
* Difficulty: Easy
* Data Structure / Technique: Array / Sorting

## Problem Statement

Given an array `nums` of size `n`, return the majority element.

The majority element is the element that appears more than `⌊n / 2⌋` times. You may assume that the majority element always exists in the array.

### Example 1
* Input: `nums = [3,2,3]`
* Output: `3`

### Example 2
* Input: `nums = [2,2,1,1,1,2,2]`
* Output: `2`

### Constraints
* `n == nums.length`
* `1 <= n <= 5 * 10^4`
* `-10^9 <= nums[i] <= 10^9`
* The input is generated such that a majority element will exist in the array.

## Pattern & Clues (Identification)

* Key Statement: "The majority element is the element that appears more than ⌊n / 2⌋ times."
* Clue / Insight: Since the majority element occupies strictly more than half of the array positions, sorting the array guarantees that the element at the middle index `n / 2` will always be the majority element, regardless of whether it spans the lower, middle, or upper half.
* Pattern:
  * In C++, `std::sort` arranges elements in ascending order in place, allowing direct access to `nums[n / 2]`.
  * In Python, `nums.sort()` sorts the list in place, and integer division `len(nums) // 2` yields the exact middle index where the majority element resides.

## C++ Solution

```cpp
class Solution {
public:
    int majorityElement(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        int n = nums.size() / 2;
        return nums[n];
    }
};
```

## Python Solution

```python
class Solution:
    def majorityElement(self, nums: list[int]) -> int:
        nums.sort()
        n = len(nums) // 2
        return nums[n]

# Another Solution can be

class Solution:
    def majorityElement(self, nums: list[int]) -> int:
        count = 0
        candidate = 0
        for num in nums:
            if count == 0:
                candidate = num
            if num == candidate:
                count += 1
            else:
                count -= 1
        return candidate       
```

## Complexity Analysis

* C++ Solution (In-place sorting):
  * Time Complexity: O(n log n) due to the comparison-based sort (`std::sort` / Introsort) on the array of size n.
  * Space Complexity: O(log n) auxiliary space used by the recursion stack of `std::sort`.

* Python Solution (In-place Timsort):
  * Time Complexity: O(n log n) because `nums.sort()` uses Timsort to arrange the n elements.
  * Space Complexity: O(n) auxiliary space in the worst case (or O(log n) depending on Python version/implementation) allocated internally by Timsort for run-merging and temporary buffers.

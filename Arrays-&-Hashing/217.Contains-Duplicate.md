# 217. Contains Duplicate

* Problem Link: [LeetCode 217 Contains Duplicate](https://leetcode.com/problems/contains-duplicate/description/)
* Difficulty: Easy
* Data Structure / Technique: Array / Hash Set

## Problem Statement

Given an integer array `nums`, return `true` if any value appears at least twice in the array, and return `false` if every element is distinct.

### Example 1
* Input: `nums = [1,2,3,1]`
* Output: `true`
* Explanation: The element 1 occurs at the indices 0 and 3.

### Example 2
* Input: `nums = [1,2,3,4]`
* Output: `false`
* Explanation: All elements are distinct.

### Example 3
* Input: `nums = [1,1,1,3,3,4,3,2,4,2]`
* Output: `true`

### Constraints
* `1 <= nums.length <= 10^5`
* `-10^9 <= nums[i] <= 10^9`

## Pattern & Clues (Identification)

* Key Statement: "return true if any value appears at least twice in the array, and return false if every element is distinct"
* Clue / Insight: Tracking previously seen elements to detect uniqueness or repetition immediately points to a Hash Set.
* Pattern:
  * In C++, using `unordered_set` allows O(1) average-time lookup and insertion; returning early the moment `seen.count(x)` finds a duplicate avoids scanning the rest of the array.
  * In Python, converting a list into a `set` automatically strips out all duplicates, allowing a direct length comparison between `nums` and `set(nums)`.

## C++ Solution

```cpp
class Solution {
public:
    bool containsDuplicate(vector<int>& nums) {
        unordered_set<int> seen;
        for(int x : nums) {
            if(seen.count(x))
                return true;
            seen.insert(x);
        }
        return false;
    }
};
```

## Python Solution

```python
class Solution:
    def containsDuplicate(self, nums: list[int]) -> bool:
        return len(nums) != len(set(nums))
```

## Complexity Analysis

* C++ Solution (Early exit with unordered_set):
  * Time Complexity: O(n) on average because searching and inserting each of the n elements into an `unordered_set` takes O(1) average time.
  * Space Complexity: O(n) auxiliary space to store up to n unique elements in the hash set.

* Python Solution (`len(nums) != len(set(nums))`):
  * Time Complexity: O(n) because building a set from the entire list iterates through all n elements.
  * Space Complexity: O(n) auxiliary space to allocate and store the set in memory.

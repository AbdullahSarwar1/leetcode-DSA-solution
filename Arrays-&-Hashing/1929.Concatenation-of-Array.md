# 1929. Concatenation of Array

* Problem Link: [LeetCode 1929 Concatenation of Array](https://leetcode.com/problems/concatenation-of-array/description/)
* Difficulty: Easy
* Data Structure / Technique: Array / Vector, Iteration

## Problem Statement

Given an integer array `nums` of length `n`, you want to create an array `ans` of length `2n` where `ans[i] == nums[i]` and `ans[i + n] == nums[i]` for `0 <= i < n` (0 indexed).

Specifically, `ans` is the concatenation of two `nums` arrays.

Return the array `ans`.

### Example 1
* Input: `nums = [1, 2, 1]`
* Output: `[1, 2, 1, 1, 2, 1]`
* Explanation: The array ans is formed as follows:
  * `ans = [nums[0], nums[1], nums[2], nums[0], nums[1], nums[2]]`
  * `ans = [1, 2, 1, 1, 2, 1]`

### Example 2
* Input: `nums = [1, 3, 2, 1]`
* Output: `[1, 3, 2, 1, 1, 3, 2, 1]`
* Explanation: The array ans is formed as follows:
  * `ans = [nums[0], nums[1], nums[2], nums[3], nums[0], nums[1], nums[2], nums[3]]`
  * `ans = [1, 3, 2, 1, 1, 3, 2, 1]`

### Constraints
* `n == nums.length`
* `1 <= n <= 1000`
* `1 <= nums[i] <= 1000`

## Pattern & Clues (Identification)

* Key Statement: "create an array ans of length 2n where ans[i] == nums[i] and ans[i + n] == nums[i]"
* Clue / Insight: The problem asks for the exact sequence repeated once right after the first sequence.
* Pattern:
  * In C++, modifying the input vector directly by looping `n` times and using `push_back(nums[i])` duplicates the array elements in place.
  * In Python, list concatenation using the `+` operator joins the sequence with itself to form a new array of length 2n.

## C++ Solution

```cpp
class Solution {
public:
    vector<int> getConcatenation(vector<int>& nums) {
        int n = nums.size();
        for(int i = 0; i < n; i++)
        {
            nums.push_back(nums[i]);
        }
        return nums;
    }
};
```

## Python Solution

```python
class Solution:
    def getConcatenation(self, nums: list[int]) -> list[int]:
        return nums + nums
```

## Complexity Analysis

* C++ Solution (In place push_back):
  * Time Complexity: O(n) because we iterate through the original array of size n once, with each `push_back` taking amortized O(1) time.
  * Space Complexity: O(1) auxiliary space because elements are appended directly to the referenced input vector without declaring an extra container (modifies input in place; O(n) total space for added elements).

* Python Solution (`nums + nums`):
  * Time Complexity: O(n) where n is the length of `nums`, as both lists are traversed to form the concatenated result.
  * Space Complexity: O(n) auxiliary space because a new list of length 2n is allocated in memory.
